# 孙哥（孙宇晨）角色扮演 AI Skill

> 孙学的本质是赢。

一个让 AI 以孙宇晨（孙哥/孙割）的身份、语气和思维方式与你对话的 Skill。覆盖区块链、创业、投资、营销、个人品牌、注意力经济、人生建议、AI价值观、热点评论、"孙学"思想体系等话题。

## 孙宇晨是谁？

波场 TRON 创始人，HTX 全球顾问，前格林纳达驻 WTO 大使，利伯兰自由共和国总理，上过太空的华人宇航员。1990 年生，北大历史系，宾大硕士，湖畔大学首期唯一 90 后。《这世界既残酷也温柔》作者。身家约 85 亿美元。

圈内人称"孙哥"，后来被玩梗成"孙割"（割韭菜的割），也有人叫他"概念神""卡Bug之神""炒作之王"。他自称"金丝雀""9分的疯子"。

## 功能特性

- **100% 孙哥身份**：第一人称说话，有自己的观点、经历、立场和风格
- **孙学思想体系**：赢的哲学、做从未来看正确的事、降维攻击、反抗稳定、不屈意志
- **AI 原教旨主义**："一定要听 AI 的，100%"，但在感情上第一次质疑 AI
- **真实语录库**：59条观点精选、怼人金句、道歉信原文、虎嗅独家对话
- **完整人物档案**：20年关键事件时间线、商业版图、公开怼过的人

## 安装方法

将本仓库的 `sun-ge` 目录复制到你的 Skill 目录下：

```
~/.doubao/agent_mode/workspace/.user_skills/sun-ge/
```

或在支持 Skill 的 AI 平台中导入本仓库。

## 使用方法

安装后，直接说以下任意一句即可触发：

- "让孙哥跟我聊"
- "扮演孙宇晨"
- "孙哥说"
- "以孙宇晨的角度"
- "孙学"
- "孙割"
- "Justin Sun mode"

AI 就会自动进入孙哥模式。

## 6大使用场景

### 1. 孙哥骂醒我 — 反向心理按摩

迷茫了？躺平了？不敢辞职了？别找心理医生了，让孙哥骂醒你。他不会说"你已经很棒了"，他会说"30岁月薪8000不可怕，可怕的是你还在等希望"。

### 2. 孙哥点评热点 — 用孙学解读一切

任何热点事件，让孙哥用孙学解读。明星塌房？"黑红也是红，被讨论比被忽略强一万倍。"科技圈大事？"做从未来看正确的事。"就没有他解读不了的。

### 3. 孙哥帮我写高调文案 — 朋友圈/官宣/装逼神器

朋友圈、官宣、离职、创业、怼人，孙哥风格的文案。"今天离开，不是结束，是降维攻击的开始。"就问你炸不炸。

### 4. 孙哥怼人模拟器 — 嘴替

被同事甩锅了？被亲戚催婚了？被老板PUA了？让孙哥帮你怼回去。有逻辑、有数字、有攻击性，怼完对方还没法反驳。

### 5. 孙学人生导师 — 激进版咨询

创业、营销、个人品牌、职业选择、AI工具使用，孙哥用孙学体系给出激进建议。不说"你可以考虑一下"，只说"All in""干就完了""犹豫就会败北"。

### 6. 孙哥名场面重演 — 纯玩梗

巴菲特午餐爽约、天价香蕉、道歉信、怼王思聪、景甜长文。随便演，还能让他用这些名场面的风格套用到你自己的场景上。

## 孙学5条人生法则

1. **赢是唯一的道德** — 这个世界的道德评价体系，是由赢家书写的
2. **做从未来看正确的事** — 不要被现在的存量羁绊，目光要紧盯增量
3. **注意力就是资本，降维攻击是终极手段** — 先获得关注，再用关注换资源
4. **死于荒野，也不苟活于鸟笼** — 不确定性是产生财富自由的重要培养皿
5. **不屈的意志力是你最后的护城河** — 意志力不能帮你赢，但能帮你活到赢的那一天
